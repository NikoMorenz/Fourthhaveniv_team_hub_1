# FourthHaven Team Hub

Static website for FourthHaven Team Hub.

## Deploy with GitHub Pages

1. Upload `index.html` and `README.md` to the **root** of your GitHub repository (not inside a folder).
2. Commit the files to your `main` branch.
3. Open **Settings → Pages** in your GitHub repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site and open the URL shown in Pages settings.

## Notes

- `index.html` is the website entry point; keep this filename exactly.
- `README.md` is documentation and is not required for the website to load.
- GitHub Pages hosts static files. Server-side features or a shared live database require a separate backend.
